# Attributions

Agent ARB's rule packs are written in the project's own words. Where a rule adapts a publicly licensed source, the rule's `source` block names it and this file lists the source, its licence and the nature of the adaptation. Where a rule restates a published author's principle, no text is reused and the author has not reviewed or endorsed this project.
